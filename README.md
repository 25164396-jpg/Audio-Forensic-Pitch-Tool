# Audio Pitch Restoration & Forensic Tool (CLI)

أداة أمنية جنائية تُنفّذ عبر سطر الأوامر (CLI) لتحليل ومعالجة التسجيلات الصوتية المعدلة، وإعادة كشف نبرة الصوت الأصلية للمتحدث من خلال التحليل الترددي.

## 📌 المشكلة والأهمية الأمنية
في التحقيقات الجنائية الرقمية والأمن السيبراني، يُلجأ أحياناً إلى تعديل طبقة الصوت (Pitch Shift) لإخفاء هوية المتحدث في التسجيلات الصوتية المخترقة أو المسربة. تتيح هذه الأداة للمحققين إمكانية توليد عدة احتمالات للترددات الصوتية واكتشاف التردد الأقرب للنبرة البشرية الطبيعية.

## 🚀 المميزات
* تعمل بالكامل من خلال سطر الأوامر (CLI) ودعم الأوامر الفرعية القياسية (`--help`, `--version`, `--config`, `--log-level`).
* معالجة شاملة للأخطاء دون إظهار أخطاء النظام للمستخدم.
* معالجة واستخراج نتائج صوتية مع الحفاظ على زمن وسرعة التسجيل الأصلي.
* خوارزمية تحليل وحساب تلقائي لنطاق التردد البشري المستهدف ($150 \text{ Hz}$).

## 🛠️ متطلبات التشغيل
* Python 3.8+
* المكتبات البرمجية:
  ```bash
  pip install numpy librosa soundfile
  ```

## 💻 طريقة التشغيل
### 1. التشغيل التفاعلي:
```bash
python script.py
```
سوف تطلب الأداة إدخال مسار ملف الصوت مباشرة.

### 2. التشغيل عبر سطر الأوامر (CLI Options):
```bash
python script.py -i "path/to/voice.wav" -o "output_folder"
```

### 3. خيارات إضافية:
* **المساعدة:** `python script.py --help`
* **الإصدار:** `python script.py --version`
* **مستوى السجلات:** `python script.py --log-level DEBUG`
* **ملف الإعدادات:** `python script.py --config config.json`

## 📊 المخرجات
توليد مجلد يحتوي على كافة الاحتمالات الصوتية الممكنة مع طباعة التقرير الترددي والخيار المقترح تلقائياً في الشاشة.
